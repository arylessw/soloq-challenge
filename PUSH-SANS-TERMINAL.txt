ÉTAPE 1 — Créer le repo sur le site
  → https://github.com/new
  → Nom : soloq-challenge
  → NE PAS cocher "Add README"
  → Create repository

ÉTAPE 2 — Double-clic sur ce fichier dans le dossier du projet :
  
     push-deploy.cmd

  → commit + push vers GitHub (remote déjà configuré : arylessw/soloq-challenge)
  → Vercel redéploie tout seul si le projet est lié au repo

  (Ancien script sans commit : git-push.cmd)

AUTRE : lancer le site sans terminal Cursor

Ouvrir le terminal dans Cursor (si tu veux réessayer) :
  • Raccourci : Ctrl + ù   (ou Ctrl + `)
  • Menu : View → Terminal
  • Ctrl + Shift + P → tape "Terminal: Create New Terminal"

Si le panneau du bas est caché : Ctrl + J
